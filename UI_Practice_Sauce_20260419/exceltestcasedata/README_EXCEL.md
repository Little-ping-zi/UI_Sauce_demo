# 测试用例 Excel 文档说明

## 📄 文件位置
`UI_Practice_Sauce_20260419/exceltestcasedata/all_testcases.xlsx`

## 📊 文档结构

### Sheet1: 元素配置清单
记录所有页面的元素定位器配置（技术层面）

**表头字段说明**

| 列 | 字段名 | 说明 |
|----|--------|------|
| A | 用例编号 | 唯一标识符，格式：TC-{页面缩写}-{序号} |
| B | 页面名称 | 所属页面（登录页面/商品页面/购物车页面） |
| C | 模块 | 功能模块分类（操作元素/验证元素/添加商品/移除商品等） |
| D | 元素键名/索引 | YAML配置中的键名或索引号 |
| E | 元素描述 | 元素的用途说明 |
| F | 定位方式 | Selenium定位类型（id/class_name/xpath等） |
| G | 定位值 | 具体的定位器值 |
| H | 操作类型 | 执行的操作（click/send_keys/text/elements） |
| I | 配置格式 | YAML配置版本（旧版testcase/check 或 新版elements） |
| J | 备注 | 额外说明信息 |

### Sheet2: 业务场景测试用例
记录完整的业务流程测试用例（业务层面）

**表头字段说明**

| 列 | 字段名 | 说明 |
|----|--------|------|
| A | 用例编号 | 唯一标识符，格式：TC-{模块}-E2E-{序号} |
| B | 用例标题 | 简洁描述测试目的和场景 |
| C | 优先级 | P0(主流程) / P1(重要) / P2(一般) |
| D | 模块 | 功能模块（端到端测试/登录管理/购物车管理等） |
| E | 涉及页面 | 测试涉及的页面列表 |
| F | 前置条件 | 执行测试前需满足的条件 |
| G | 测试步骤 | 详细的操作步骤（多行文本） |
| H | 测试数据 | 使用的测试数据（用户名、密码、商品等） |
| I | 预期结果 | 期望得到的结果（多行文本） |
| J | 用例类型 | 主流程/功能测试/异常测试/边界测试/用户体验等 |
| K | 备注 | 额外说明

## 📝 注意事项

1. **配置格式区分**
   - 旧版（login.yaml）：使用 testcase/check 分段 + 数字索引
   - 新版（product.yaml, cart.yaml）：使用 elements 统一结构 + 键名映射

2. **用例编号规则**
   - TC-LOGIN-xxx: 登录页面
   - TC-PROD-xxx: 商品页面
   - TC-CART-xxx: 购物车页面

3. **定位方式优先级**
   - id（最优）
   - class_name
   - css_selector
   - xpath（最后考虑）

4. **操作类型说明**
   - click: 点击操作
   - send_keys: 输入文本
   - text: 获取文本内容
   - elements: 获取元素列表
